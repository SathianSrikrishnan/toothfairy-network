# Archive

This folder keeps older planning, launch-readiness, and agent setup notes out of the public repo root while preserving them for context.

- `legacy-root/` contains former root-level setup and strategy files.
- `planning-session/` contains the old `.planning` session metadata.
- `launch-readiness/` contains pre-cleanup launch-readiness notes.
- `plans/` contains dated implementation plans from the sprint.

These files are historical reference material, not runtime configuration.
