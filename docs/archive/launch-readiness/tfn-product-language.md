## Parent Language

Use these words when trust, safety, recovery, and the main family action matter:

- memory
- first forever memory
- keepsake
- family link
- parent-controlled
- Smile Fund

## Magical Language

Use this sparingly and teach it through visuals:

- Toothlight

A Toothlight is the glowing keepsake: the tooth, the drawing, the smile, and the story around the moment. It should feel like a magical object before it feels like a technical term.

## Technical Language

Use this underneath the parent story, especially in proof, FAQ, post-mint, Colosseum, and Smile Fund contexts:

- parent-controlled digital wallet
- built on Solana
- on-chain proof
- wallet

## Voice

Tanda should not be called CEO in parent-facing copy. Use story-native authority:

- Tanda from Tooth Fairy Network
- Tanda, Keeper of the Network
- Tanda, Head Tooth Collector

Recommended default for emails: `Tanda from Tooth Fairy Network`.

## Homepage Positioning

Primary headline:

> Turn a lost tooth into your child's first digital wallet.

Supporting promise:

> Start with a Toothlight memory. Parents control the wallet, the timing, and the family link. Built on Solana.

The emotional order is parent control, low-friction memory creation, Solana proof, then the magical Toothlight layer. Avoid broad "free" promises in polished copy because AI enhancement and Solana minting have real underlying costs.

The homepage should not repeat the same trust cues as hero chips when the subheading already carries them. Use the room below the hero to teach the ritual, then bridge into the story world.
